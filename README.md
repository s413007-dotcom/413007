# 彈珠英雄：元素碰撞 (Marble Heroes: Elemental Collision)

《彈珠英雄：元素碰撞》是一款結合傳統彈射物理與 RPG 元素相克策略的 HTML5 網頁遊戲。玩家需要精準控制英雄發射的角度與力道，利用元素克制與壁面反彈引爆多重連擊（Combo），在有限的回合內擊敗所有敵人！

---

## 🎮 遊戲玩法與設計概念

* **彈射碰撞**：透過拉曳彈珠進行發射，利用物理碰撞與牆壁反彈進行攻擊。
* **元素克制**：英雄與敵人均帶有火、水、木、光、暗不同元素，相克屬性可造成額外大幅傷害。
* **團隊切換**：提供多位不同屬性與特性的英雄，玩家可根據戰局隨時切換出場英雄。
* **連擊與關卡**：連續碰撞可觸發 Combo 倍率加成，回合數有限，考驗玩家的彈射策略與角度選擇。

## 🤖 使用的 AI 提示詞 (Prompts)

本專案主要透過 AI 協助完成程式架構、物理引擎開發與 UI 視覺設計，以下為核心開發提示詞：

1. **原型構想與邏輯生成**：
   > 「幫我把彈珠英雄元旭碰撞這遊戲製作出來我要能玩的成品」
2. **完整視覺與系統擴充**：
   > 「幫我把彈珠英雄元素碰撞這遊戲製作出來我要能玩的成品，需要有五大元素相克、選角系統、連擊特效與響應式介面。」

## ✅ 已完成的功能

- [x] **物理與彈射引擎**：支援向量拉射、力道計算、雙體彈性碰撞與壁面反彈。
- [x] **五大元素克制系統**：
  - 🔥 火克木 | 🌲 木克水 | 💧 水克火
  - ✨ 光 🔮 暗 相互強烈克制 (+50% 傷害)
- [x] **多英雄切換**：
  - 🔥 **元旭** (火)：高碰撞傷害
  - 💧 **滄海** (水)：均衡連擊
  - 🌲 **森羅** (木)：高血量與回復特化
  - ✨ **極光** (光)：超高速貫穿
- [x] **打擊視覺特效**：浮動傷害數字、碰撞粒子火花、爆破粒子與 Combo 彈出動畫。
- [x] **Web Audio API 音效**：免載入外部音檔，透過合成器即時生成發射、碰撞與爆炸音效。
- [x] **關卡與回合機制**：自動生成敵人陣容，動態計算關卡難度與回合數限制。
- [x] **跨平台響應式 UI**：支援 PC 滑鼠操作與行動裝置觸控。
